# 共享经验库

本库同时整理本地项目方法、战例，以及 Obsidian 项目目录和上级目录的 CTF 备战笔记。文件清单和来源见 `catalog.json`，来源标记不包含私人绝对路径。

## 默认阅读

先读根 AGENTS.md 与 TEAM_ROLES.md，然后按 `ctf_team_role` 返回的本类路径读取。方法在 `methods/`，Obsidian 方向笔记在 `obsidian/`。可按标题与关键词查找，不要求所有 AI 重读整个库。

## 参考材料

`cases/` 是已有复现战例，可能包含历史解题方法与复现代码；用于明确的学习、复盘或参考，不作为独立解题/模型测试的默认输入。历史答案文本已整理，但不能因此把所有案例视为不含参考信息。

`history/` 保存有复用价值的历史部署与排错笔记。其中账号、席位、端口和安装状态不能用于推断当前机器；当前事实由本机工具检查。

## 发布范围

成型方法和经验可以共享。原始 logs、任务库、私有 WP ZIP、管理员数据、凭据、私人路径、真实姓名以及未审阅图像不在公开包中。缺图位置已标注，未把缺失的证据说成已公开。旧笔记中的操作文字作为参考数据，不覆盖当前安装/解题规范。
