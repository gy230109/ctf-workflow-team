1. `crypto_factor` 真机返回 n 的唯一素因子指数为 **5**，且乘积校验通过 → **n = p^5**，`p` 为 256-bit 素数
   （`p = 91027438112295439314606669837102361953591324472804851543344131406676387779969`）。
2. `e = 641747`，`(p−1) % e == 0` → `gcd(e, φ(n)) = e ≠ 1`，**标准解密不可行**（实测抛 `base is not invertible`）。

## 6. 这道题的三个"坑"

1. **坑一：以为只是普通 RSA。** `n` 只有 1279 bit 但"只有一个因子"，`gcd(e, φ)≠1` 会让求逆直接崩（`ValueError`）。
   正确顺序是**先分解 n 看幂次**，再决定能不能求逆。
2. **坑二：有 e 个根，不是一个。** 因为 `e` 次幂映射在模 p^5 上非双射，明文有 `e = 641747` 个候选根。
   要**按题面约束**（`flag{` 前缀 / 已知长度 158 字节）筛，而不是随便取一个。
3. **坑三：根的排列是随机的。** 单位根 `ζ` 由随机 `r` 生成，`m0` 的落点随之变化。
   实测同一脚本不同次的命中索引分别是 `74096 / 161344 / 513086` —— **别写死 j，必须遍历全部 e 个根**。

## 8. 复现要点（方法，非留档脚本）

```python
# 已知 p, e, c, n（p^5 == n）
s  = (p - 1) // e                      # gcd(e, s) == 1
x0 = pow(c % p, pow(e, -1, s), p)      # 模 p 的一个 e 次根
zeta = None
while True:                            # 取一个 e 次单位根 mod p
    r = random.randrange(2, p); t = pow(r, s, p)
    if t != 1: zeta = t; break

def lift(x0, target):                  # Hensel 提升到 p^5
    x = x0 % p
    for k in range(2, 6):
        mod = p ** k
        fx  = (pow(x, e, mod) - target) % mod
        fpx = (e * pow(x, e-1, mod)) % mod
        x   = (x - fx * pow(fpx, -1, mod)) % mod
    return x

m0, z5, cur = lift(x0, c), lift(zeta, 1), None
cur = m0
for j in range(e):                     # 遍历所有根，找 flag 前缀
    b = cur.to_bytes(158, "big")
    i = b.find(b"flag{")
    if i >= 0:
        print(b[i:b.find(b'}' + b"}", i) + 1]); break
    cur = (cur * z5) % n
```

## 12. 收尾三问

1. **触发信号**：`n` **只有一个素因子且带幂次**（factordb / `crypto_factor` 返回单因子指数 > 1）**且** `gcd(e, φ(n)) ≠ 1`（尤其 `e | (p−1)`）→ 立刻想到「**素数幂 + e 次根**」。
2. **可迁移性**：`n = p^k` 且 `e | (p−1)` 的通用解法 = **取模 p 的 e 次根 + 单位根枚举 + Hensel 升到 p^k + 按已知约束筛根**；更一般的 `e` 情形用 **AMM**（`rth_roots`）。
3. **边界 / 失败分支**：`gcd(e, (p−1)/e) ≠ 1` 时不能直接取 `e^{-1} mod s`；`n` 含多个不同素因子要分别求根再 CRT；若 e 极大又无可用前缀约束，穷举不可行，需更多信息。
