## 5. 已验证事实

> 下列每一步均已**独立复现**（本人重新实现，见 §9 脚本）。

1. 文件大小 `1,009,338 = 138 + 580*4*435`（实测 `biBitCount@28 = 24`、头 124 字节、宽高 580×435）；
   → BMP 头**谎报 `biBitCount=24`**，实际是 **32bpp BGRA**（V5 头 124 字节）。
   把头部该字段改 24→32 后即可正常显示。
2. 升维后的正常画面：二向箔"降维打击"图，文字 `DIFOIL` 与
   `CONSUME, THEN LEAVE THE WORLD AS TWO DIMENSION`。
3. **蓝通道 B 的 bit0 位平面**：按**行序**读字节得到 `Who am I?`，按**列序**读字节得到 `David`
   → 提示数学家 **David Hilbert**（配图是人像）。
4. **第 4 通道 `rgbReserved`(=A) 的 bit0**，在坐标 (x 226–353, y 153–280) 恰好是一个
   **128×128 的二值网格**（已按 `FLIP_TOP_BOTTOM` 摆正，用 numpy 行序数组）。
5. 用 **7 阶希尔伯特曲线** `d2xy(n=7, d)` 把该 128×128 网格降维成 **2048 字节** →
   得到一个 **C 语言 Quine**（`#include <stdio.h>` … `char* a(char* s)` …）。
6. 该 Quine 文本的**第 11 行行尾有 200 个空白字符**（实测 **103 个空格 + 97 个 Tab**）；
   空格→0、Tab→1 → 200 bit → **25 字节** = `<历史答案已移除>`。
7. 复现脚本/产物：
   - 脚本 `artifacts\hilbert.py`（解析 BMP 为 32bpp BGRA、取 `A&1`、截 `grid = A[153:281, 226:354]`、
     实现 `d2xy(n,d)`、尝试 8 种朝向×反色、按可打印率挑选、写 `output.bin`；
     最佳朝向 `(flipx=0, flipy=0, tr=0, inv=0)`，可打印率 **0.906**）。
   - 产物 `artifacts\output.bin`（2048 字节的 C Quine）。

```python
d = open(r'threebody.bmp','rb').read()
w, h = 580, 435; px = d[138:]
rgba = np.array(Image.frombytes('RGBA',(w,h),px,'raw','BGRA').transpose(Image.FLIP_TOP_BOTTOM))
A = rgba[:, :, 3] & 1
grid = A[153:281, 226:354]          # 128x128 二值网格
# 7 阶希尔伯特：d2xy(7, d) 生成 128*128 条曲线点，按最佳朝向（flipx=0,flipy=0,tr=0,inv=0）取样
# → 打包成 2048 字节 output.bin（C 语言 Quine）
# 再对 output.bin 第 11 行行尾 200 个空白（空格→0 / Tab→1）取 25 字节 → flag
```
