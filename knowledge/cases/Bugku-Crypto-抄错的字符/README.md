## 2. 题面

> 老师让小明抄写一段话，结果粗心的小明把部分数字抄成了字母，还因为强迫症把所有字母都换成大写。
> 你能帮小明恢复并解开答案吗：`QWIHBLGZZXJSXZNVBZW`

三条线索：① 原文是"一段话"（后经编码）② **部分数字被抄成形似字母** ③ **所有字母被强制大写**（暗示原文有大小写之分）。

## 3. 解题链（怎么想出来的）

```
QWIHBLGZZXJSXZNVBZW   （19 位，全大写字母）
  │ ① 全大写 + "数字被抄成字母" ⇒ 原文是**字母数字混合**的编码
  │      ⇒ 首选 Base64（大小写敏感、含 0-9）
  │      长度校验：19 mod 4 = 3 ⇒ Base64 合法（去 padding 后 mod 4 ∈ {2,3}）
  │      （Base32 排除：去 padding 长度 mod 8 只能是 0/2/4/5/7，19 mod 8 = 3 ✗）
  │ ② 补一个 '=' 凑 4 的倍数
  │ ③ 形似数字还原：I→1、G→9、Z→2、S→5
  │ ④ 大小写恢复：H→h、B→b、L→l、V→v、W→w
  ▼
QW1hbl92ZXJ5X2Nvb2w=
  │ ⑤ base64 -d
  ▼
Aman_very_cool  ⇒  <历史答案已移除>
```

**省事技巧**：Base64 可以 4 位一组独立解。先试 `QW1h` → 解出 `Ama`，路线立刻确认，不用整串瞎试。

| 抄错的 | 还原 | 原因 |
|---|---|---|
| `I` | `1` | 数字 1 被抄成形似的大写 I |
| `G` | `9` | 数字 9 被抄成形似的大写 G |
| `Z` | `2` | 数字 2 被抄成形似的大写 Z |
| `S` | `5` | 数字 5 被抄成形似的大写 S |
| `H B L V W` | `h b l v w` | 原小写字母被"强迫症"统一大写 |

## 6. 这道题的坑

1. **`Z` 有两重身份**：位置 8/14/18 是数字 `2`，位置 9 就是字母 `Z`。题目说"**部分**数字抄成了字母"——不能无脑全局替换。
2. **大小写信息不可逆**：全大写把"哪些是小写"抹掉了，只能靠 Base64 解出可读明文来反证——所以必须能看懂结果（`Aman_very_cool` 是人名/短语，才敢定案）。
3. **先判 Base32 会走弯路**：全大写字母串很像 Base32，但长度 19 直接违规（合法去 padding 长度 mod 8 只能是 0/2/4/5/7）。先用长度证伪，省一大圈。
4. 补 `=` 是必须的：19 位不是 4 的倍数，不补位大部分解码器直接报错。
