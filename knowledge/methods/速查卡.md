# 速查卡 · 拿到任何附件先跑这 5 步

**默认注入项（≈1 KB）。长文档在 `01`~`05`，只在需要深挖时翻。**

**密码题分流**：若附件给 RSA 方程、`p^r*q` 或逆元关系，先看 [06-密码SOP](06-密码SOP-连分数与素数幂RSA.md)。下面算法栈/IL 步骤用于 .NET 附件。

**要秒题**：拿到附件先跑下面 5 步，再按 [秒题索引](秒题索引.md) 的「识别特征 → 一招解法 → 命令」对号入座。

## 1 分诊（0 成本，必须第一步）
`体积 / mod16 / 重复密文块 / 头部 magic / 全量可打印字符串`
→ 一次拿到：分组长度、加密模式、封装格式、算法栈线索

## 2 找算法栈（一次 grep 拿完）
符号：`RijndaelManaged / Aes / CreateDecryptor / TransformFinalBlock / Deserialize / Rijndael / SHA256 / PBKDF2`
→ 然后**必须**追到 `set_Mode(?)` 与 `set_Padding(?)` 的**实参**

## 3 读 IL 只看三处（别从头读）
① `call/callvirt/newobj` 的 token ② `ldtoken + InitializeArray` ③ `ldstr`
（其余控制流等这三处看完再回来看）

## 4 定密钥来源
静态数组 → **`FieldDef → FieldRVA → RVA→文件偏移`**；schema 是 **`[RVA(u4), Field(ti)]`（RVA 在前！）**

## 5 算 & 验
`z3`（含 and/or/mux）或 `GF(2) 高斯消元`（纯异或）
**最后一次调用永远留给验证。**

## 五条红线
1. **重复密文块 ⇒ ECB**。免费判据，先做，别急着爆破。
2. **AES 外面几乎总套一层 XOR / 加常量 / 字节反转** → 必查一层字节级变换。
3. 元数据里的长 hex 名字（`== SHA256(某常量)`）= 编译器给**静态数组**起的哈希名，**不是密钥派生**。
4. **宽整数 → 窄字节数组**（`>>(j*8) & 0xFF`）⇒ 未知量骤降，**先降维再上 z3**。
5. 单步可能 **> 60 s** 的操作（爆破 / SMT）在预算模式下必须换做法或提前预留。
