## 〇、通用基础工具（全员必装）

这些是所有方向都用得上的基础工具，不管你主攻哪个方向都要装。

| 工具 | 用途 | Windows 安装 | Linux 安装 | 备注 |

| **010 Editor** | 十六进制编辑器（最强） | 官网下载 | 官网下载 Linux 版 | 模板解析功能极强，分析二进制必备 |
| **Wireshark** | 网络流量抓包分析 | 官网下载 | `sudo apt install wireshark` | Misc 流量分析方向必装 |

### Kali Linux —— 零基础最强开局

如果你是零基础，**直接装一个 Kali Linux 虚拟机**，它预装了上面 80% 的工具，省去逐个安装的麻烦。

```
1. 下载 VMware Player（免费）或 VirtualBox
2. 下载 Kali Linux 镜像：https://www.kali.org/get-kali/
3. 新建虚拟机，分配至少 4GB 内存 + 40GB 硬盘
4. 安装后执行更新：sudo apt update && sudo apt full-upgrade -y
```

Kali 预装的关键工具：Burp Suite、Wireshark、Nmap、John the Ripper、Hashcat、sqlmap、Metasploit、foremost、binwalk、steghide 等。

### 1.4 Burp Suite 配置要点

```
1. 安装后先设置浏览器代理 127.0.0.1:8080
2. 导入 CA 证书：浏览器访问 http://burp → 点击 CA Certificate → 导入浏览器
3. 常用模块：
   - Proxy（代理）：抓包改包
   - Repeater（重放）：反复测试 payload
   - Intruder（爆破）：批量 fuzz
   - Decoder（解码）：各种编码转换
4. 安装插件（BApp Store）：
   - HaE（Highlighter and Extractor）：高亮响应中的关键信息
   - Autorize：权限绕过测试
   - JSON Beautifier：美化 JSON 响应
```

## 二、PWN 方向工具清单

PWN 是强网杯的重头戏，学习曲线陡峭但分值高。需要较好的 C 语言和汇编基础。

### 2.1 核心工具

| 工具 | 用途 | 安装方式 | 优先级 |
|------|------|---------|--------|
| **pwntools** | Python PWN 框架：构造 payload、远程交互 | `pip install pwntools` | ★★★★★ |
| **IDA Free / IDA Pro** | 逆向分析神器：反汇编+反编译 | 官网下载 | ★★★★★ |
| **GDB + pwndbg** | 动态调试 ELF 程序 | 见下方配置 | ★★★★★ |
| **checksec** | 检查二进制保护机制（NX/PIE/Canary等） | `pip install checksec.py` 或 pwntools 自带 | ★★★★★ |
| **ROPgadget** | 搜索 ROP 链 gadget | `pip install ROPgadget` | ★★★★☆ |
| **one_gadget** | 一键找 libc 中的 execve gadget | `gem install one_gadget` | ★★★★☆ |
| **LibcSearcher** | 根据 libc 函数地址识别 libc 版本 | `git clone https://github.com/lieanu/LibcSearcher` | ★★★★☆ |
| **patchelf** | 修改 ELF 的动态链接库路径 | `sudo apt install patchelf` | ★★★☆☆ |
| **seccomp-tools** | 分析 seccomp 沙箱规则 | `gem install seccomp-tools` | ★★★☆☆ |
| **pwninit** | 自动设置 PWN 题目环境（匹配 libc） | `cargo install pwninit` | ★★★☆☆ |

### 2.2 GDB + pwndbg 配置

```bash
# 1. 安装 GDB
sudo apt install gdb gdb-multiarch

# 2. 安装 pwndbg（比 peda 更好用）
git clone https://github.com/pwndbg/pwndbg
cd pwndbg
./setup.sh

# 3. 验证
gdb # 进入后应该显示 pwndbg 界面
```

### 2.3 pwntools 常用模板

```python
from pwn import *

# 设置架构
context.arch = 'amd64'      # 或 'i386' / 'arm'
context.log_level = 'debug'

# 连接远程
# p = remote('hostname', port)

# 连接本地
# p = process('./challenge')

# 常用操作
p.sendline(payload)         # 发送一行
p.send(payload)             # 发送原始数据
p.recvuntil(b'xxx')         # 接收直到指定字符串
p.recvline()                # 接收一行
p.interactive()             # 交互模式（拿 shell 后用）

# 地址打包
p64(addr)                   # 64位地址打包
p32(addr)                   # 32位地址打包
```

### 2.4 PWN 环境注意事项

```
1. Windows 用户强烈建议用 WSL 或 Kali 虚拟机做 PWN 题
   - pwntools 在 Windows 上功能不完整
   - GDB 只能在 Linux 上用

2. 需要准备多个 libc 版本
   - 使用 patchelf 替换题目 libc 进行本地调试
   - 或用 pwninit 自动处理
   - libc 数据库：https://libc.rip/

3. 安装多架构支持（ARM/MIPS 题目）
   sudo apt install gdb-multiarch
   sudo apt install qemu-user
```

### 4.2 IDA 配置要点

```
1. IDA Free 8+ 已包含反编译器（F5），零基础够用
2. 常用快捷键：
   - F5：反编译为 C 伪代码
   - N：重命名变量/函数
   - Y：修改变量类型
   - Shift+F12：字符串窗口
   - Space：切换图形视图/文本视图
   - G：跳转到指定地址
3. 推荐插件：
   - FindCrypt：识别加密算法常量
   - Lazy IDA：快捷功能集
```

### 4.3 Ghidra 配置要点

```
1. 需要 JDK 17+：sudo apt install default-jdk
2. 下载地址：https://github.com/NationalSecurityAgency/ghidra/releases
3. 解压后运行 ghidraRun.bat（Windows）或 ghidraRun（Linux）
4. 优势：完全免费、开源、支持协作分析
5. 反编译器：CodeBrowser 窗口中自动显示 C 伪代码
```

## 七、快速安装脚本

### 7.1 Linux/Kali 一键安装核心工具

```bash
#!/bin/bash
# 强网杯 CTF 工具一键安装脚本（Linux/Kali）
# 使用方法：chmod +x install_tools.sh && ./install_tools.sh

echo "[*] 更新系统..."
sudo apt update && sudo apt upgrade -y

echo "[*] 安装基础工具..."
sudo apt install -y git python3 python3-pip gdb gdb-multiarch nmap wireshark \
    foremost binwalk steghide outguess pngcheck tcpflow tshark strace ltrace \
    upx patchelf testdisk autopsy audacity ruby ruby-dev default-jdk

echo "[*] 安装 Python 库..."
pip3 install pwntools pycryptodome gmpy2 sympy requests beautifulsoup4 \
    lxml scapy Pillow volatility3 angr frida-tools ROPgaptcha

echo "[*] 安装 Ruby 工具..."
sudo gem install one_gadget zsteg seccomp-tools

echo "[*] 克隆工具仓库..."
mkdir -p ~/ctf-tools && cd ~/ctf-tools
git clone https://github.com/RsaCtfTool/RsaCtfTool
git clone https://github.com/maurosoria/dirsearch
git clone https://github.com/pwndbg/pwndbg && cd pwndbg && ./setup.sh && cd ..

echo "[*] 安装 SageMath（较慢，耐心等待）..."
sudo apt install -y sagemath

echo "[+] 安装完成！"
```

### 7.2 Windows 用户建议

```
Windows 用户强烈建议：
1. 安装 WSL2（Windows Subsystem for Linux）
   - 管理员 PowerShell 执行：wsl --install
   - 重启后在 WSL 中安装 Ubuntu/Kali

2. WSL 内安装上述所有 Linux 工具
   - PWN/Crypto 方向工具在 WSL 中运行
   - Web 方向 Burp Suite 直接在 Windows 安装
   - 逆向 IDA/Ghidra 直接在 Windows 安装

3. 或者直接装 Kali Linux 虚拟机
   - VMware Player + Kali 镜像
   - 虚拟机内工具最全，开箱即用
```

## 十、常见问题

**Q: Windows 能做 PWN 题吗？**
A: 不建议。pwntools 在 Windows 上功能受限，GDB 无法使用。用 WSL2 或 Kali 虚拟机。

**Q: IDA Free 够用吗？**
A: 零基础阶段够用。IDA Free 8+ 已包含反编译器（F5 功能）。后期如果需要调试功能可考虑 Ghidra（免费）或 IDA Pro。

**Q: SageMath 太大了必须装吗？**
A: Crypto 方向必须装。很多攻击（Coppersmith、LLL 格、椭圆曲线）需要 SageMath 的数学能力。至少 20GB 空间。

**Q: 工具太多装不过来怎么办？**
A: 先装 Kali 虚拟机，它预装了大部分工具。然后按方向逐步补充。7月第一周只需要装第一优先级的工具。

**Q: 4个人需要装一样的工具吗？**
A: 不需要。每人主攻一个方向，优先装自己方向的工具。但通用工具（Python、Git、Kali、Burp）建议全装。
