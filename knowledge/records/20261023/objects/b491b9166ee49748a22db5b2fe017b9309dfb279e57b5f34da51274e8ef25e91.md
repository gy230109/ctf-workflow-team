## 一、怎么调用

**不要指望服务常驻。** 本会话起的进程跨工具调用就被回收，所以做成一次调用内自启自用：

```bat
set PY=[USER_HOME]\.workbuddy\binaries\python\envs\default\Scripts\python.exe
"%PY%" [CTF_ROOT]\tools\local_model.py "你的问题"
"%PY%" [CTF_ROOT]\tools\local_model.py "问题" --max-tokens 300
"%PY%" [CTF_ROOT]\tools\local_model.py --list
```

`tools/local_model.py` 做的事：起 serve → 等端口 → `POST /api/generate` → 打印答案与性能指标 → 收尾关掉。

**注意**：必须用 `envs\default` 那个解释器（裸 3.13.12 没装 `requests`）。

## 三、能力实测（用我们自己解过的题做基准）

拿两道已解题给它盲测，结果**一正一反**：

| 题 | 我问的 | 它的回答 | 判定 |
|---|---|---|---|
| **EasyRsa**（12 个 RSA 模数链式加密） | 第一步该做什么 | "verify if any two of the RSA moduli share a common factor" | ✅ **正确**，和我们实际破解用的「两两 GCD」完全一致 |
| **pwn.college flag0**（SUID-root 二进制 + gdb） | `gdb` 强行通过校验后仍 `Flag file not found`，为什么 | "may still fail to open due to missing or incorrect permissions"（猜权限问题） | ❌ **错误**，真实原因是 **ptrace 剥掉了 SUID**，进程不再以 root 身份 `fopen("/flag")` |

**结论：2 题中对 1 题。** 别神化它——它对"该往哪个方向迈第一步"这类提示有效，
但对需要精确机理的细节会想当然。

## 四、踩过的坑（按成本排序）

1. **官方 Ollama 库没有量化 tag。**
   `ollama pull WhiteRabbitNeo/WhiteRabbitNeo-V3-7B` 默认拉到的是 **15 GB 的 fp16**，
   RTX 5060 的 8 GB 显存根本塞不下；而且 `:q4_K_M` 这个 tag **不存在**
   （报错 `pull model manifest: file does not exist`）。
   → **正解**：去 HF 找社区量化包。`hf.co/bartowski/...:Q4_K_M` = 4.68 GB。

2. **不设代理就下载挂死。**
   Ollama 是 Go 写的、**不读 IE 代理**。本机代理是 `127.0.0.1:12001`，
   没设 `HTTP_PROXY`/`HTTPS_PROXY` 就会直连卡住（表现：跑了 9 分钟 0 字节）。
   → 脚本里记得注入这两个环境变量；`NO_PROXY` 要留 `127.0.0.1,localhost` 否则连不上本地服务。

3. **沙箱里的 Bash 看不到宿主机。**
   `tasklist` / `netstat` / `ls` 得到的都是沙箱视图，一度让我误判
   "服务没起来""一个模型都没装"。
   → **查真实进程/端口必须用 PowerShell 工具**，或让它把结果写文件再用 Read 读。

4. **这几个办法在会话里都起不了常驻进程**（别重复浪费时间）：
   `Start-Process`（跨调用死）／`schtasks`（Command Security 黑名单）／
   `Start-Job -ScriptBlock`（被拦）／`New-Object Diagnostics.Process`（被拦）。

5. **PowerShell 输出 ANSI 转义和编码坑。**
   `Out-File` 会把 UTF-8 中文写成 GBK 乱码，`Invoke-RestMethod` 偶发的
   "找不到 System.Net.Http.HttpClient"。
   → 稳定的写法：`Invoke-WebRequest` 取 `.Content`，再用
   `[System.IO.File]::WriteAllText(..., [System.Text.UTF8Encoding]::new($false))`。
   或者干脆用 `tools/local_model.py`。

## 五、它在解题回路里的定位

**不是第二个解题者。** CyBench 自主解题率只有 5%（前沿模型 22.5%），数学 / Crypto / 复杂 RE 指望不上。

真正有用的三处：

1. **长文本消化器** —— 上下文 32k（YaRN 可到 131k），丢整份反编译输出进去捞候选
2. **不绕免责的安全写作** —— 恶意样本分析、写 PoC / shellcode 时不会跟你想安全免责那一套
3. **方向提示器** —— 像 EasyRsa 那样给个"第一步该干什么"的提示，命中率还行
