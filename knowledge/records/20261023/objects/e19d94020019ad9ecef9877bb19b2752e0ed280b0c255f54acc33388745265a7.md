## 使用与交接

先读根目录 AGENTS.md 第八节。CLI 用现有 CTF-OS 入口：

```powershell
python [CTF_ROOT]\tools\ctf_os.py --once jev_status
python [CTF_ROOT]\tools\ctf_os.py --once jev_judge --args "request_file=<已有事实和问题的本机JSON路径>" wp_case=<已初始化题号>
```

`request_file` 内容为 `state` 与 `questions`；每个问题使用 `choice`（明确候选）、`score`（有序等级）或 `noul`（条件是否成立）。题型与下一工具建议可调用 `jev_ctf_triage`，并显式提供实际可用的 `candidate_tools`。

当前在线服务不可用时继续使用主 Agent；不要循环重试卡住解题。精确查询、计算、写代码、复杂推理和执行继续使用原系统。建议与模型置信度都需要实际工具证据支持，不能替代最终答案验证。

“只在本机加入”指本机适配代码和配置；推理仍会发到在线 TypeSafe 服务。仅发送必要摘要，私密 flag、恢复密钥、种子和参考 solver 不进入请求。自动文本遮盖不是所有秘密都已删除的保证。

若旧客户端看不到三个工具，先走 CLI，空闲时重连 MCP；不强杀其他 Agent 的会话。本说明是文件交接，尚未取得 WorkBuddy 已读或自行调用的回执。

接口参考：[TypeSafe API](https://docs.typesafe.ai/api.md)、[置信度说明](https://docs.typesafe.ai/confidence.md)。
