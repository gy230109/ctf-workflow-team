# 秒题索引 · 识别特征 → 一招解法 → 现成命令

> 目的：**见题就秒**。看到特征直接跳到「一招」，不再从头推。
> 每条都对应已实测的手法；对应 SOP/战例在括号里。
> 用法：拿到附件先跑 [速查卡.md](速查卡.md) 的 5 步分诊，再回本表按特征对号入座。

## A. 附件形态（0 成本，先看一眼）

| 特征 | 判断 | 一招 | 命令/去向 |
|---|---|---|---|
| 附件**只有 `task.py`、无 `out.txt`** | 动态附件（参数在服务端） | 别硬算：从公开题解取真实参数（**标来源**），本地只做算法复现 | 队列标 `blocked`；见战例 not_only_rsa/babyrsa |
| 附件 = `flag.enc`(hex) + `app/*.dll`(.NET) | 内嵌密钥 | `strings dll` 先试常量当键；不行上反编译 | SOP §10 |
| 附件含 `public_key/parms` 且 `main.py` 起服务 | **在线题**（缺 secret_key/密文） | 本地无法复现，需连服务端 | 队列标 `blocked` |
| 附件是 **GIF/动图：每帧是窄条、帧间内容在动** | 同一窗口里**多个静态图交错播放** | 按**帧号取模**分组（`i % k`），同余帧**竖向拼接**成完整图 → 逐组解码；多张图常把 flag 分段（如 base64 前后半）拼起来 | 已实测：DUCTF21 how-to-pronounce-gif（120 帧=10 个 QR×12 条带，`i%10` 分组）|
| `run.sh` = `xxd -p -c 16 \| while read l; do dotnet X.dll $l; done` | **逐 16 字节块加密** ⇒ 每块独立 | 按 ECB 处理 | SOP §10 |

## B. RSA 一眼判据（最快秒杀区）

| 特征 | 判断 | 一招 | 命令/工具 |
|---|---|---|---|
| `crypto_factor(n)` 返回**单因子 + 指数 k>1** | `n=p^k` | `φ=p^{k-1}(p-1)` | `crypto_factor` |
| 上一条 + `gcd(e, φ)≠1`（尤其 `e \| p−1`） | 幂映射非双射 | **e 次根 + 单位根枚举 + Hensel**，按 `flag{` 前缀筛根 | SOP §8（not_only_rsa）|
| `gcd(N, c) ≠ 1` | **共因子泄露** | 直接 `p=gcd(N,c)→φ→d=c 的逆指数` | `math_gcd`；SOP §11（check-little）|
| `e=3` 且 `c` 是**完全立方**（`iroot(c,3)^3==c`） | 小指数（无 mod 回绕） | `iroot(c,3)` → 直接出明文 | 纯 Python |
| 同一明文用同一 `e` 加密到**多个 N** | Hastad 广播 | CRT 合并 + 开 e 次方 | `crypto_crt` |
| 多个 `N` 有**公共因子** | 共模 | 两两 `gcd` | `crypto_shared_factors` |
| `d` 小（`< N^0.25`） | Wiener | `e/N` 连分数收敛 | SOP §1–3 |
| `d` 中（`< N^0.292`） | Boneh-Durfee | 二元格（`f=x·y²+…`） | `crypto_lll` / kali sage；SOP §9 |
| `p ≡ q (mod 2^t)` 且 `d` 中 | **共享低位 + 小 d** | `nth_root(2)`+`v0` → 二元格 LLL + resultant | kali sage（babyrsa，45×45 约 51 s）|
| 明文 = `flag`+随机填充、定长 | 可用"约束筛根" | 遍历全部根按 `b"flag{"` 筛 | SOP §8 |
| `e` 与 `φ` 互素但 `N` 太大分不动 | 常规 | 先查 `gcd(N,c)`、再查是否 `N=p^k` | 本表 B 段 |

## C. 对称/混合

| 特征 | 判断 | 一招 |
|---|---|---|
| 密文出现**重复 16B 块** | **ECB**（免费判据） | 按块独立处理 |
| 密文 = 16 的倍数且有 `iv` | CBC | 需 key+iv；key 常来自 RSA 段 |
| AES 调用前有 XOR / 加常量 / 字节反转 | 外层字节级变换 | **必查一层**（别只看 AES）|
| 元数据里长 hex 名 = `SHA256(某常量)` 的字段名 | 编译器给静态数组起的哈希名 | **不是**密钥派生，别追 |
| key = `bytes([m ^ 6 for m in magic_numbers])` | 魔数异或得键 | 按常量异或重放 |
| `long_to_bytes(key)[:16]` | 密钥**截断** | 解密时同样截断 |

## E. 新版能力（2026-10-15 实测，已端到端验证）

| 特征 | 判断 | 一招 | 命令/要点 |
|---|---|---|---|
| 附件是**异架构 ELF**（aarch64/arm/mips/riscv64） | 本机跑不了 | QEMU user 执行 | `qemu_run arch=<arch> local_file=<附件>`；可传 `argv`/`stdin`；动态程序需对应 sysroot（现只有 aarch64）|
| 可执行程序要**连续调试**（断点/单步/寄存器） | 一次性反汇编不够 | 连续 GDB/Pwndbg 会话 | `kali_debug_session`：`start(target=本题内文件)` → `command` → `status`(同一 PID) → `close` |
| Web 题要看**真实渲染**/交互链 | 静态 HTML 不够 | 连续浏览器会话 | `web_browser_session`：`start` → `navigate` → `snapshot` → `fill`/`click` → `screenshot` → `close` |
| 图片/音频疑似**隐写** | 需提取 | zsteg/steghide/stegseek | `misc_stego action=zsteg\|info\|extract\|seek`（extract 要 `passphrase`；seek 要 `wordlist`）|
| 要现成的 **RSA/ECC 攻击实现** | 别重造 | crypto-attacks 固定提交库 | `crypto_library action=list query=<关键词>` → `action=read method=<点号模块名>` → `action=import` |
| 想确认新增依赖**到底可不可用** | 别只看文档 | 现测运行时状态 | `ctf_runtime_status`（免 confirm）：命令路径 + 版本探针 + 密码库 + sysroot + 残留会话 |

**用法与坑（实测）**
- 四个重工具 `qemu_run` / `misc_stego` / `web_browser_session` / `kali_debug_session` **都要 `confirm=true`**；`ctf_runtime_status`、`crypto_library` 不需要。
- **输入必须在本题目录内**：传任意 Kali 绝对路径会被拒（`Input must be a regular file inside this case`）；不在 case 里就先 `kali_run` 拷进去。
- 调试命令**受限**：只有 inspect/断点/单步；`file/source/shell/python/attach` 一律被拒 → 用 `info files` / `info registers` / `break` / `stepi`。
- 浏览器**只收显式 http(s)**（`data:` URL 被拒）；origin 必须在 `allow_origins` 内，**改白名单要 close→start**；start 约 8 s；截图是真 PNG（1280×800）。
- `crypto_library.method` 用**点号模块名**（如 `attacks.rsa.wiener_attack`），**不是文件路径**。
- 隐写/截图产物**自动回传本机** `…\cases\<case>\downloads\…`，带 sha256。
- 每类重工具**同时只开一个**会话，闲置 5 分钟 / 总时长 30 分钟自动退出；重启不延续。用完 `close`。
- 后台服务用 `setsid nohup … &`；**别用会匹配自身命令行的 `pkill -f`**（自杀，rc=-15）。
- **自建极简 ELF 慎用**：161 B 纯 syscall 的 aarch64 静态 ELF 被 qemu 11 以 `Exec format error` 拒收（6 种变体同样），验收请用**真实 ELF**。

## F. 铁律（不因"秒"而松）
1. **绝不臆造 flag**：flag 必须来自**本机真机输出**。
2. 用公开题解的**参数或手法**必须**标来源**；结论以本地复算为准（`p*q==n`、重加密 == 密文）。
3. 复现失败记「**未复现**」，不许写成已解。
