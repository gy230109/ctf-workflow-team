# tools · 工具集

**路径已全部解耦，两个变量分工**：

| 变量 | 含义 | 用途 |
|---|---|---|
| `SCRIPT_DIR` | 脚本所在目录（自动取 `__file__`） | import 同目录的 `dn.py` |
| `BASE` | 数据工作目录，默认 = `SCRIPT_DIR`，`GM_BASE` 可覆盖 | 读 `embedded.dll` / `gamemessage` 等 |

```bat
:: 把 GM_BASE 指向本次题目的工作目录
set GM_BASE=[CTF_ROOT]\战例库\QWB2022-GameMaster-Blackjack\artifacts
python [CTF_ROOT]\tools\il.py embedded.dll all
```

> ⚠️ **别混**：`import dn.py` 必须用 `SCRIPT_DIR`。
> 早期版本让它走 `GM_BASE`，一设环境变量就 `FileNotFoundError: ...\artifacts\dn.py`。
> **代码依赖用 `SCRIPT_DIR`，数据文件用 `BASE`。**

推荐解释器（**自带 z3**）：

```
[USER_HOME]\.workbuddy\binaries\python\versions\3.13.12\python.exe
```

## 规则

1. **新写的脚本先放这里**，能复用就登记；一次性的一次性脚本用完即弃，别污染目录。
2. 所有脚本**默认只读**，不修改输入文件（输出另存）。
3. 脚本里**不许硬编码绝对路径**，用 `BASE` / `GM_BASE` 或 `sys.argv`。
4. 危险操作（爆破、SMT 长时间求解）必须在 docstring 里**标注预估耗时**。
5. 改完脚本**至少自检语法**：

```bat
"[USER_HOME]\.workbuddy\binaries\python\versions\3.13.12\python.exe" -m py_compile <script>.py
```
