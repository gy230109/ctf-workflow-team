## 一、题型：**走迷宫**

babyrev 每一关换一套生成方式（05 逐字符掩码 / 06 cmov 链 / 07 迷宫），

## 二、★ 三个信号，反汇编之前就能看出「这题不一样」

| 信号 | level05/06 | level07 |
|---|---|---|
| 格式串 | `%24s` | **`%100s`**（key 最长 100） |
| `.text` 体积 | 1669 / 3061 B | **837 B**（代码极少） |
| `.data` 体积 | 16 B | **608 B**（数据巨大） |
| 导入表 | 有 `sscanf` 之类 | **只有** `scanf / printf / fopen / fread / puts` |

不是"比字符串"，是"查表 + 状态机"。

## 三、校验函数 0x4012f0 的真面目

```asm
0x4012f7: xor ecx, ecx        ; ecx = x
0x4012f9: mov edx, 1          ; edx = y   -> 起点 (0, 1)
0x4012fe: sub eax, 0x41       ; 字符 - 'A'
0x401301: cmp al, 0x36
0x401303: ja  fail            ; > 0x36 就不是合法指令
0x401308: jmp qword ptr [rax*8 + 0x402070]   ; 跳转表，55 项
```

四个移动块：

| 地址 | 指令 | 方向 | 字母 |
|---|---|---|---|
| `0x401320` | `sub ecx, 1` | 左 | **W** |
| `0x401360` | `add ecx, 1` | 右 | **S** |
| `0x401368` | `add edx, 1` | 下 | **D** |
| `0x401370` | `sub edx, 1` | 上 | **A** |

> 🔴 **字母必须从跳转表里读出来，不能靠猜** —— `W/A/S/D` 看着像 WASD，
> 但 `A` 是**上**、`D` 是**下**，跟直觉（A=左 D=右）正好相反。

每次移动后：
```asm
0x40132d: lea rsi, [rsi + rsi*2]   ; rsi = x*3
0x401337: lea rax, [rax + rsi*4]   ; rax = y + 12*x   ← 索引是 **列优先**
0x40133b: mov r8d, dword ptr [rax*4 + 0x404080]  ; .data 里的 12×12 dword 网格
0x401343: test r8d, r8d
0x401346: jne fail                 ; 非 0 = 墙，死
0x401348: cmp edx, 0xb             ; y == 11 ?
0x40134d: cmp ecx, 1               ; x == 1  ?
0x401350: je  success              ; 终点 (1, 11)
```

两个容易读错的细节：
1. **索引是 `y + 12*x`（列优先）**，不是常见的 `x + 12*y`。
   搞反会得到一张"看起来也像迷宫"的错图，而且照样能 BFS 出一条路径 —— 错得很隐蔽。
2. **先移动、后检查，起点那格不检查。**
