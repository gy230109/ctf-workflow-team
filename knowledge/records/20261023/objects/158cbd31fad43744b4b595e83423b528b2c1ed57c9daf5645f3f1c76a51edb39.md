## §4 Muteki 的解法脚本（原文照抄）

`run/solve.muteki.py`：

```python
from math import gcd
from Crypto.Util.number import long_to_bytes, inverse

e = 65537
ns = [int(l) for l in open('output.txt')]
import re
c = int(re.findall(r'c = (\d+)', open('task.py').read())[0])

m = c
for n in reversed(ns):
    p = gcd(ns[0], ns[1])
    q = n // p
    d = inverse(e, (p-1)*(q-1))
    m = pow(m, d, n)

print(long_to_bytes(m))
```

**它是自己找到"两两 GCD"这个突破口的** —— 第 3 次工具调用就是 GCD 扫描，
和我方独立解法的第一步完全一致。

## §5 ★ 关于"朴素连除到底对不对"—— 实测校正

项目此前的规则写着：

> **链式 RSA 逆推必看**：`pow(m_{i+1}, d_i, n_i)` 只给模 `n_i` 的余数，
> 真实 `m_i` 还满足 `m_i < n_{i-1}` → 候选要试 `r + t*n_i`，DFS + 可打印性剪枝。

而 worker 写的是**朴素连除**（每层直接取余数，不做候选分支），**并且它对了**。两者冲突，我实测查清了。

### 实测数据

**（a）朴素连除本地复跑，结果正确**：

```
朴素连除结果: b'GWHT{gixkJl7SJTcpLOL9zqwo}'   与参考答案一致: True
```

**（b）带约束的分支枚举确实会分叉**（不是"只有一个候选"）：

```
逐层(层号, 进入候选数, 产出候选数):
 (11,1,1) (10,1,2) (9,2,3) (8,3,2) (7,2,4) (6,4,4) (5,4,4)
 (4,4,3) (3,3,3) (2,3,4) (1,4,4) (0,4,20)
→ 最内层 20 个候选，其中**只有 1 个是可打印 ASCII**
```

> 上一版 `verify_easyrsa.py` 报"候选数 = 1"，是因为它在最内层加了**可打印性剪枝**；
> 去掉剪枝是 20 个。**这两个数不矛盾，但之前那句表述不够精确，此处更正。**

**（c）朴素连除成立的前提，逐层核对**：

```
 层 |  m_i 位数 | n_i 位数 | m_i < n_i ?
 ----+-----------+----------+------------
  0 |    207    |   1023   |   True
  1 |   1021    |   1023   |   True
  2 |   1022    |   1023   |   True
 ... （12 层全部 True）
```

**（d）n 的分布并不"紧贴"**：

```
n_i / 2^1023 ∈ [0.576, 0.992]     ← 比值最大可差 72%
```

### 结论（三条，都要记）

1. **朴素连除在本题成立，是因为实例恰好每层 `m_i < n_i`**（实测所有 `m_i` 为 1019–1022 位，
   而所有 `n_i` ≥ 0.576 × 2^1023 > 2^1022）。
2. **这不是结构性保证。** `n_i` 跨度有 72%，换个实例完全可能出现某一层 `m_i > n_i`，
   那时朴素连除会**静默输出错误结果**（不报错，只是序列里多加了若干个 `n_i`）。
3. **所以原规则是对的，要保留**；worker 的朴素脚本属于**这一题撞对**。
   → **判断标准不能靠"脚本跑通了"，要靠"正向加密回比"。**
   本次三重验收的判据③（正推 12 次与题面 `c` 完全一致）正是干这个用的。

## §7 未验证假设

1. **`p` 是素数** —— 没跑 Miller-Rabin。不影响求解（正推复算已间接覆盖）。
2. **为什么这一题每层 `m_i < n_i`** —— 只验了"事实成立"，没证明"为什么必然成立"。
   统计上 12 层全部落在 1019–1022 位是偏紧的，可能是我对分布建模不准，**存疑**。
3. **单样本不能代表成功率** —— 这是 1/1，只能说明"能跑通"，**不能说明"解题率高"**。
   要谈成功率必须跑一批（见 §8）。
4. **朴素 vs 带约束两种写法在本题的差异** 没做对照实验（只验了朴素结果正确）。
