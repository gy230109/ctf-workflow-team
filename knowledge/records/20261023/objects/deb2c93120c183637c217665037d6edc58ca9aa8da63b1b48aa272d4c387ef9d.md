# 11 · 分发包：给别人用的那一版

`10-解题工作流Skill.md` 讲的是**怎么用**，这一篇讲的是**怎么发出去**。
发出去之前必须做一件事：**脱敏**。自己用的版本里全是本机路径和已解出的 flag。

## 产物位置

| 用途 | 路径 |
|---|---|
| 源（本机在用的） | `[USER_HOME]\.workbuddy\skills\ctf-orchestrator\` |
| 归档（解压版） | `[CTF_ROOT]\分发\ctf-orchestrator\` |
| 归档（压缩包） | `[CTF_ROOT]\分发\ctf-orchestrator.zip`（30,920 B / 11 个文件） |

**改任何内容都要改源目录，再重新复制 + 重新打包**，别直接改分发版。

## 打包命令

```bat
"[USER_HOME]\.workbuddy\binaries\python\versions\3.13.12\python.exe" ^
  "D:\工具\WorkBuddy\resources\app.asar.unpacked\resources\plugins\workbuddy-builtin\skills\skill-creator\scripts\package_skill.py" ^
  "[USER_HOME]\.workbuddy\skills\ctf-orchestrator"
```

注意：它**不接受 `--help`**（会被当成路径），且产出落在**当前工作目录**，
不是 skill 目录——打包完记得把 zip 挪回来。

## 脱敏：三层扫描，一层都不能少

发出去之前跑这三条，任何一条有命中就别发：

```bash
cd <skill 目录>
# 1. flag 与答案
grep -rIn "pwn\.college{\|GWHT{\|flag{\|secrets" .
# 2. 本机绝对路径 / 用户名
grep -rIn "Lenovo\|C:\\Users\|D:\\强网杯" .
# 3. 凭据与本机网络配置
grep -rIn "cookie\|token\|PRIVATE KEY\|127.0.0.1:12001" .
```

### 实际清掉的东西

| 文件 | 原来写的 | 改成 |
|---|---|---|
| `references/cases.md` | flag0 的 MD5 `7de38f3c…` 和答案 `secrets` | 只留"7 位小写英文单词"和题号 |
| `scripts/verify_flag.py` | 文档串里拿真实 MD5 和真实答案当示例 | 换成 `<魔数>` / `<你算出来的答案>` 占位 |
| `references/pitfalls.md` | 本机代理 `127.0.0.1:12001` | 改成"查注册表 `ProxyServer`" |
| `SKILL.md` | 同上 | 同上 |

**最容易漏的一条**：MD5 hash 本身不是 flag，但**挂到公开仓库上别人在线反查就能拿到答案**，
等于没脱敏。所以 hash 一起抹掉，只留"题在哪、方法是什么"。

## 分发渠道：GitHub 那条路当前走不通

2026-10-10 实测：

| 动作 | 结果 |
|---|---|
| `create_repository` | **403 Resource not accessible by integration** |
| `create_or_update_file`（写文件） | **403 同上** |
| `get_me` / 搜索仓库 | ✅ 正常（能读到 `gy230109` 名下 4 个公开仓库） |

**结论：GitHub 连接器挂的是只读令牌**，能读不能写，建库也不行。
本机 `git` 有（2.55.0），但**没有 GCM、凭据管理器里也没有 GitHub 条目**，
所以命令行也推不上去。

三条出路：

1. **重新授权连接器**（勾选写权限），或给一个 classic PAT（`repo` 作用域）临时用一次；
2. **发布为应用**——把 skill 做成一个带下载链接的静态页面，直接拿分享链接；
3. **人工传** —— 现在**没插 U 盘**（只有 C: D:），插上再拷。

## 换机器要改什么

设计上**换机器只改 `nodes.json`**，别改脚本。三个环境变量：

| 变量 | 作用 |
|---|---|
| `CTF_PY` | 带依赖的 Python 解释器 |
| `CTF_KALI_FLOW` | Kali 桥接编排脚本 |
| `CTF_ARENA_FLOW` | 靶场编排脚本（如 pwn.college） |

在**没有 Kali、没有靶场、没有本地模型**的干净机器上实测过：
`local_python OK`，其余一律 `NOT_CONFIGURED` / `OFF(可选)`，**主流程照跑**。
