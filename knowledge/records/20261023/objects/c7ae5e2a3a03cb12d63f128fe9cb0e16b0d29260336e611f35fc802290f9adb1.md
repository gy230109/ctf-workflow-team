5. **程序性质**：只是"整蛊"——显示搞笑文本 + 播放 mp3 + 调系统音量；**代码里没有实际删除文件/安装软件的调用**，

## 6. 这道题的坑

1. 🔴 **manifest 补空格的位置**：`requireAdministrator`(20) → `asInvoker`(9) 需要补 11 个空格到等长；
   **空格写在引号内**（`level="asInvoker           "`）会让 Windows 报 `14001 并行配置不正确`；
   必须写成 `level="asInvoker"           `（**空格在引号外**）。
2. **直接运行必被拦**：`WinError 740 请求的操作需要提升` —— 要么提权（会弹 UAC），要么 patch manifest。
3. **flag 不在文件里，在 GUI 控件里**：全段字符串扫描（含中文）**什么都扫不到**；
   必须**运行 + 读窗口/控件文本**（`EnumChildWindows` + `GetWindowTextW`）才拿得到。
4. **不要一看到"已为您删除/已安装"就以为有毒**：本题对应代码段（0x4016a7）**只显示文本**，
   无实际删除/安装调用；**读代码比读字符串可靠**。
5. **打乱的 flag 要用"字符集匹配"做判据**：密文长度与目标格式同长、字符多重集一致 ⇒ 基本可断定是重排（栅栏/转置），
   枚举"步长残差 / 行列转置 / 奇偶分离"即可命中。
6. 易语言程序**字符串多在 `.data` 段**（不是 `.rdata`），扫描要覆盖全部段。

## 8. 复现要点（方法）

```python
s = "fgaag_!l{_oun}amb_ob"
# 解密：按 7 个位置一组做"同余残差分离"
flag = "".join("".join(s[i] for i in range(r, len(s), 7)) for r in range(7))
assert flag == "flag{ma_bao_guo_nb!}"

# 正向复算（列主序写入 / 行序读出）
n, cols = len(flag), 7
rows = (n + cols - 1) // cols
grid = [[""] * cols for _ in range(rows)]
k = 0
for c in range(cols):
    for r in range(rows):
        if k < n: grid[r][c] = flag[k]; k += 1
assert "".join("".join(row) for row in grid) == s
```
