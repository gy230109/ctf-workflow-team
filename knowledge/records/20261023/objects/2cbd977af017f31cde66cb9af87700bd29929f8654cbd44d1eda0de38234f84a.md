## 5. 已验证事实

1. `message`（1,105,858 B）实为 **41 个串接的 PDF**：
   `%PDF` 计数 = 41（首偏移 0 / 26932 / 53907 / 80867 / 107821）。
2. `generate.py`：`poly[0] = bytes_to_long(flag.encode())`；`K = len(poly)`；
   用 Shamir 秘密共享，生成 K 个 `(x, y)`，其中 `y = eval_poly(x)`，
   `eval_poly(x) = Σ c_i·x^i mod prime`。
3. 每份 PDF 用**独立置换过的 DejaVuSansMono 子集字体**渲染一行文本；
   其 `ToUnicode` 是**恒等映射**，直接抽文本得到乱码（即 `out.txt` 那种
   `u _ /S/I&3DSiI3I&S&/D33RRDSRi/8RiR&/DV/…`）。
4. 解法成立：逐份 PDF 抽 `FontFile2` → 用 fontTools 把每个字形轮廓与随包
   `DejaVuSansMono.ttf` 逐字节比对（**95/95 字形全部命中**）→ 得到该份 PDF 的字符映射表
   → 还原文本 = `<prime>` + 40 组 `x=…, y=…`。
5. 对 `x=0` 做 **Lagrange 插值**求 `poly[0]` → `bytes` → flag：
   **`flag{0bfu5c4t10n_0nly_g3ts_y0u_s0_f4r}`**（本地复算得到）。
6. 格式差异：`task.json` 的 `flag_format` 写 `FLAG{...}`，但实测真实 flag 外皮是**小写 `flag{}`**
   （本题以实测为准）。

## 9. 复现思路（示意，非留档脚本）

> 以下只描述方法步骤，**不是**当时留档的实测脚本（脚本本身未归档）。
> 不要直接照抄当"已跑通的代码"引用。

```
1. pdfs = split(message, b'%PDF-')[1:]              # 41 段
2. 对每份 pdf：
     font = 解析出 FontFile2 的 TTF 字节
     for glyph in font.glyphs:                       # 95 个
         mapping[glyph] = 在 DejaVuSansMono.ttf 里逐字形轮廓匹配到的字符
     文本行 = 用 mapping 解码该 PDF 的内容流
3. text = 拼出 'p = <prime>' 与 40 行 'x = <x>, y = <y>'
4. poly0 = lagrange_at_zero([(x_i, y_i) for ...], prime)
        = Σ y_i · Π_{j≠i} (-x_j)/(x_i - x_j)   (mod prime)
5. flag = long_to_bytes(poly0).decode()
```
