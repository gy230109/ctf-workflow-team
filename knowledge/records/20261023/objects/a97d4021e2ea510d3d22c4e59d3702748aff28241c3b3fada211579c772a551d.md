## 一、备战总览与时间规划

### 1.1 赛事背景

强网杯由国家网信办与河南省人民政府指导，信息工程大学、郑州大学等单位联合主办，是国内含金量最高、竞争最激烈的国家级网络安全赛事之一。第九届（2025年）线上赛吸引超过3000支战队、1.3万余名选手参赛，线上赛晋级线下赛名额仅32支。线上赛采用 Jeopardy 解题模式，题目覆盖二进制逆向、Web安全、密码学、IoT安全、AI安全等多个方向。

### 1.2 Web 方向赛题特点

根据历年赛题分析，强网杯 Web 方向具有以下显著特点：

| 特点 | 说明 |
|------|------|
| **漏洞链综合考察** | 单题通常不是孤立的漏洞利用，而是多漏洞组合形成完整攻击链 |
| **框架深度利用** | 常涉及 ThinkPHP、Spring Boot、Flask、Django 等主流框架的 CVE 与特性利用 |
| **多语言代码审计** | Java、Python (Flask/Django)、PHP、Node.js 的源码审计交替出现 |
| **WAF/过滤绕过** | 题目环境常内置 WAF 或过滤规则，需绕过技巧 |
| **内网渗透联动** | 部分题型获得 Web Shell 后需横向移动至内网 |
| **真实场景仿真** | 近年 RW（Real World）趋势明显，模拟真实业务环境 |

## 五、组队建议

### 5.1 理想队伍配置

强网杯线上赛每队最多10人。Web方向选手建议队伍配置：

| 角色 | 人数 | 职责 |
|------|------|------|
| **Web主力**（你） | 1-2人 | Web类题目主攻，代码审计主力 |
| PWN/二进制方向 | 1-2人 | 逆向工程、漏洞利用 |
| Crypto/密码学方向 | 1人 | 密码分析类题目 |
| Misc/杂项方向 | 1人 | 取证、隐写、流量分析 |
| 机动/全能型 | 1人 | 辅助各方向、信息收集与工具支持 |

### 5.2 校内组队建议

- **联系渠道**：寻找安阳师范学院计算机学院/网络空间安全相关专业的同学，通过校内CTF社团或信息安全兴趣小组组队
- **指导教师**：尽早联系一位愿意指导CTF竞赛的教师（计算机/信息安全方向），强网杯支持指导教师参与
- **日常协作**：建立QQ/微信群，每周1次线上讨论会，共享学习笔记和PoC库
- **分工原则**：每人选定1-2个主攻方向深度钻研，避免"全而不精"

### 5.3 联合组队（可选）

若校内Web力量不足，可考虑与其他高校联合组队。国内CTF联合战队常见模式（如Nu1L、W_M、天命等均为联合战队），但需符合强网杯"同一高校/企业/院所"的线下赛要求。线上赛对同单位限制较宽松，组队更灵活。

4. **复盘**：对比Writeup，分析差距，更新PoC库
5. **指标**：目标是赛前能在4小时内独立解出3道中高难度Web题
