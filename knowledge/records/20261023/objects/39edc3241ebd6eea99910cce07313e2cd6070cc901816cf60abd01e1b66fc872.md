# Factor 解题记录

Flag：`qwb{8633ce6d-fece-4cf1-8f0f-f27e5bf6d678}`。

原始 Factor.zip 的 SHA256 为 `2d2504be6632fd4e272aa2af4032469528d0395ec14e730610e36ac17a7879fb`。附件只包含 task.py，下面直接解析其公开参数，没有运行生成代码。源码 return 中的变量名存在笔误，解题使用给出的公式和实际输出整数。

## 第一层：相近大素数使模数比泄露小素数比

模数为 `n11=p11²*q11`、`n12=p12²*q12`。两个 1792 位素数非常接近，因此 `n11/n12` 近似 `q11/q12`。遍历 `n11/n12` 的连分数收敛分数，寻找分子分母分别整除两个模数、且剩余商为平方数的候选。

本题在第 310 个收敛分数处得到精确因子。恢复欧拉函数 `phi=p*(p-1)*(q-1)`，计算私钥，解密 c11、c12，得到第二层的两个参数 m1、m2。

另外用恢复后的因子核实了 Legendre 条件：`2*abs(n11*q12-n12*q11)*q12 < n12`，这保证该小素数比出现在收敛分数中。

## 第二层：模逆数的小余项

这一层 `N=p⁷*q`，`phi=p⁶*(p-1)*(q-1)`。公开参数 m1 满足 `m1*d1=1 (mod phi)`，且 d1 只有 672 位。

计算 `s=inverse(m1,N)`。因为 N 和 phi 都含有因子 p⁶，可得 `s=d1+t*p⁶`，于是：

`s/N = t/(p*q) + d1/N`。

余项很小，实际满足 `2*d1*(p*q)² < N`。遍历 `s/N` 的连分数即可恢复分母 p*q。本题第 558 个收敛分数满足条件；`N/(p*q)=p⁶`，取精确六次方根获得 p，继而恢复 q 和 phi。

用 e2=65537 解密 c2 得到 672 位整数 b。恢复的 d1、d2 都为 672 位。

## 第三层：除掉已恢复的 b，再重复攻击

第三层 `e3=inverse(a,phi3)*b`。先检查 e3 能被 b 整除，再计算 `e'=e3/b`。与第二层同理，`inverse(e',N3)=a+t*p3⁶`；a 只有 672 位，连分数在第 598 个收敛分数恢复分母 p3*q3，得到第三层因子。

实际 `gcd(e3,phi3)=1`，因此可计算 `inverse(e3,phi3)`，解密 c3，得到上述 flag。
