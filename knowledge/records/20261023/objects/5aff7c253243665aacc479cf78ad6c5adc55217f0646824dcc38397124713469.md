## 6. 这道题的坑

1. **附件不给数值**：`Crypto-babyrsa.zip` 仅 `task.py`；拿不到 `n/e/c` 时无法从零算，须从公开题解取参数并**标注来源**。
2. **不是普通 RSA，也不是单纯共享低位**：`φ` 是 `(p²−1)(q²−1)`（复数单位群），且 `d` 小 → 单靠"共享低位求 k"不够，要上**二元格**（论文 `A new attack on some RSA variants` 给了同参数例子）。
3. **sage 多项式慢**：与 not_only_rsa 同款坑——提升/构造用**整数运算**别用符号多项式（本题 LLL 已 51 s，符号多项式更慢）。
4. **明文拆两段**：`m` 是复数，`flag` 按**前半/后半**拆成 `(re, im)`，还原时也按此拼接。

## 8. 复现要点（方法）

```python
# 真机 sage（Kali）：由 n,e 出发
u0 = ZZ(Mod(n, 2**100).nth_root(2, all=True)[0])
v0 = ZZ((2*u0 + (n - u0**2)*pow(u0,-1,4**100)) % 4**100)
a1 = int(v0 * pow(2**(200-1),-1,e) % e)
a2 = int(-((n+1)**2 - v0**2) * pow(2**400,-1,e) % e)
a3 = int(-pow(2**400,-1,e) % e)
X, Y = ZZ(2*n**(alpha+delta-2)), ZZ(3*n**(0.5-2*beta))   # alpha≈2.0, beta=100/1000, delta=0.70
# 二元格 m=4,t=4：F(x,y)=x y^2 + a1 x y + a2 x + a3 → LLL → resultants → (x,y)
p_plus_q = 2**(2*100)*y + v0
p = (isqrt(p_plus_q**2 - 4*n) + p_plus_q)//2 ; q = n//p
# 解密（本地）
d = pow(e, -1, (p*p-1)*(q*q-1))
m = complex_pow(c, d, n)          # Gaussian 模幂（re/im 模 n）
flag = long_to_bytes(m.re) + long_to_bytes(m.im)
```

## 11. 收尾三问

1. **触发信号**：看到密钥生成里 **`p、q` 由"同一随机低位 k + 2^t·高位"构成**（⇒ `p ≡ q mod 2^t`），再叠加**小 `d`** → 想到「低位恢复 + 二元格」。
2. **可迁移性**：共享低位 / 小 `d` 的 RSA 变体 → 用 `nth_root(2)` 恢复 `(p+q)` 低位，构造小根多项式 → **二元格 LLL + resultant** 解出 `(x,y)`；复数域 RSA 记得群阶是 `(p²−1)(q²−1)`。
3. **边界 / 失败分支**：共享位数太少（`β` 过小）或 `d` 超出可解区间时格不收敛；`nth_root(2)` 需 `p≡q`（本例成立）；纯共享低位而无小 `d` 时单二元格未必够，需换更强格或改用共享低位专用攻击。
