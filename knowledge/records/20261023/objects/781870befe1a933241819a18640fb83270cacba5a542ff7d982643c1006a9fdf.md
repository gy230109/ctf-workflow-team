## 其他 Agent 怎么用

先读根目录 AGENTS.md 第九节，再读取实际 `/tools` 或 CLI 工具目录。不要套用上午云端代码里的名字、参数、路径或旧数量。

```powershell
python [CTF_ROOT]\tools\ctf_os.py --once ctf_profile --args category=reverse
python [CTF_ROOT]\tools\ctf_os.py --once ctf_specialist_status
```

正式解题先 `wp_init`，后续调用加同一 `wp_case`；附件用 `local_file`，同题客机产物用 `target`。复杂参数用本机 JSON 的 `request_file`；不要把未验证结果写成 observed。每个关键结论用真实输出/回放支持，再 `wp_note`、`wp_status`、`wp_build`。

本次新增代码和配置仅在本机运行；团队仓库、模板和分发包未由本轮改写。新环境保存在 Kali 虚拟磁盘中，日常开机复用既有自动恢复入口，无需重复安装。自动启动的基础就绪不代表各题型完整验收，使用前现测。
