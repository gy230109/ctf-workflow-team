# 发给别人的话 —— 直接复制

> 三选一，看对方是谁。**整段复制，不用改。**

---

## 一、发给 AI（它能配 MCP：Trae / Claude Desktop / Cursor / 各类 agent）

```
我本机有一套 CTF 作战系统（CTF-OS，36 个工具），你直接接：

{"mcpServers":{"ctf-os":{"command":"[USER_HOME]\\.workbuddy\\binaries\\python\\envs\\default\\Scripts\\python.exe","args":["[CTF_ROOT]\\tools\\ctf_os.py","--stdio"],"cwd":"[CTF_ROOT]\\tools"}}}

接上后先 tools/list 看全部能力和参数。能力包括：数论/密码（gcd、模幂、
模逆、RSA 解密、多模数共享因子）、编码转换、GameBoy ROM 逆向、XOR 爆破、
flag 格式校验；Kali 上的 file/strings/binwalk/radare2/objdump；
本机的 gdb/objdump；以及查装备状态、派题给 Muteki。

三条规矩：
1. nmap/hashcat/sqlmap/派单 这类危险工具必须带 confirm:true，否则会被拒绝。
2. Kali 是另一台机器，分析我本机文件时用 local_file 参数，系统会自动上传。
3. flag 相关工具只做格式校验，不产出答案 —— flag 我自己跑。
```

## 二、发给 AI（它只会跑命令行，不会 MCP）

```
我本机有 CTF 工具箱，你能执行 shell 就直接调，不用配任何东西：

python [CTF_ROOT]\tools\ctf_os.py --once <工具名> --args <参数>

先看有哪些工具：
python [CTF_ROOT]\tools\ctf_os.py --selftest

参数用免引号的 key=value 写法（JSON 里的双引号会被 shell 吃掉，实测踩过）：
  python [CTF_ROOT]\tools\ctf_os.py --once math_gcd --args values=48,60
  → {"ok": true, "result": {"result": 12}, "tool": "math_gcd"}

  python [CTF_ROOT]\tools\ctf_os.py --once util_hex --args text=ABC
  → {"ok": true, "result": {"result": "414243"}, "tool": "util_hex"}

多个参数用空格分隔：--args a=1 b=2 ；布尔写 confirm=true ；十六进制写 0x1f 能认。
参数名写错它会把正确参数名和示例回给你，照着改一次就对。
危险工具（nmap/hashcat/sqlmap/派单）要带 confirm=true。
flag 只做格式校验，不替我出答案。
```

## 三、发给人类同事

```
我电脑上跑着一套 CTF 工具系统，36 个工具，地址 http://127.0.0.1:8787 。
MCP 客户端指向 http://127.0.0.1:8787/mcp 就能直接用；
不会 MCP 就 POST http://127.0.0.1:8787/call 发 JSON，
先 GET http://127.0.0.1:8787/tools 看能力清单。
（前提是我这边服务开着。）
```

## 四、如果对方在外网 / 别的机器

上面三条都是**本机范围内**的用法。要让别的机器上的 agent 也能调，得我这边先做两件事：

1. 服务监听改成 `0.0.0.0` 并设令牌：
   `set CTF_OS_TOKEN=<令牌>` 然后 `python ctf_os.py --host 0.0.0.0 --port 8787`
   （`python ctf_os.py --make-token` 可生成令牌）
2. 告诉对方地址和令牌，让它在请求里带 `X-CTF-OS-Token` 头。

🔴 这么做之前先想清楚：等于把 Kali、本机 shell、派单能力都开给了对方。
