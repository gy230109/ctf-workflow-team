| **前30分钟** | 全员快速浏览所有题目，标记难度（⭐简单/⭐⭐中等/⭐⭐⭐难） |
| **前1/3时间** | 优先攻克简单题，每人做自己方向的题，快速拿分 |
| **中段** | 挑战中等题，遇到卡壳超30分钟换题，不要死磕 |
| **后1/3时间** | 尝试难题，互相协助，Web 题可以多人一起看 |
| **最后30分钟** | 检查已做出的题是否提交成功，不要放弃任何一分 |

### 关键原则
1. **不死磕**：单题超过40分钟没思路，先跳过
2. **多沟通**：做出题第一时间在群里说思路，帮队友节省时间
3. **稳拿分**：简单的 Misc/Web 题先做完，确保基础分到手
4. **留时间**：最后留30分钟检查提交，避免低级失误
