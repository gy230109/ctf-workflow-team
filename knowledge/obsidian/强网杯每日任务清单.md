## 7月2日（周三）— 编码题刷起来

**今日目标**：通过做题掌握常见编码

**知识点引入（10分钟）**：
- 常见编码特征：
  - Base64：`ZmxhZw==`（大小写+数字+/+=）
  - Hex：`666c6167`（只含 0-9a-f）
  - URL编码：`%66%6c%61%67`（%xx 格式）
  - 摩斯密码：`..-. .-.. .- --.`
  - 栅栏密码：<本机配置，不分发>

**做题**：
- [ ] CTFHub → 密码学 → Base64/32/16 各做 2 题
- [ ] CTFHub → 密码学 → 摩斯密码 2 题
- [ ] CTFHub → 密码学 → 栅栏密码 2 题

**遇到什么学什么**：
- CyberChef 怎么用？→ 把编码贴进去，用 Magic 模块自动识别
- 编码嵌套怎么办？→ 一层一层解，先 Base64 再 Hex 再 URL
- 用 Python 解码：`import base64; base64.b64decode('xxx')`

**今日产出**：9 题截图 + 编码特征速查表（边做边记）
