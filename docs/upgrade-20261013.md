# 2026-10-13 增量升级与队友操作

这版以队友已安装的第一版为基础。原 56 个接口扩展到 82 个：六类专项 23 个、经典密码 3 个；辅助脚本、题库接入与详细 Trae Skill 同步发布。各机器的工具和依赖以实际目录/验收为准。

## 已安装用户

Git 安装：先保存自己的代码改动，`git pull --ff-only`。ZIP 安装：新包解压到旁边，使用旧环境的 Python 执行新包 `tools/upgrade_install.py --source <新包> --target <旧安装> --plan`，核对后去掉 `--plan` 应用。该工具只复制发布清单、逐文件验证并保留代码备份，不整体覆盖目录。

之后从原安装目录执行：

```powershell
.\update.ps1 -InstallSpecialists
.\install-trae.ps1
.\start.ps1 -Reload
.\.venv\Scripts\python.exe -X utf8 tools\ctf_team.py verify
.\.venv\Scripts\python.exe -X utf8 tools\ctf_os.py --once ctf_specialist_status
```

下载慢可仅本次加 `-PipIndex https://mirrors.aliyun.com/pypi/simple`，不改全局 pip/TLS。只补某类加 `-Category <web|pwn|reverse|crypto|misc|forensics>`。系统原生工具按缺项安装，专项 venv 与原 venv 分开。

保留 `.venv`、本机 `config/*.json`、`bridge/config`、身份、账号、WP、日志和题目。更新后当前工具调用结束再重连 ctf-os MCP；HTTP 用 start.ps1 -Reload，只停止已核对属于同一安装且没有连接客户端的旧监听器，其他端口进程不终止。新技能的客户端发现需在本机实际确认。

| 第一版题库 | 题源目录与附件下载入口 | 见 questionbank.md 的实际文件状态和验收边界 |

## 已验证与边界

队长本机六类专项已通过 65 项回归、28 项自建附件检查与真实截图/WP 往返；这不是其他五台电脑验收。另有 Trae 侧自建样例验证记录，但发布版本仍须独立验证。经典密码能力不保证短密文稳定成功。内存镜像、完整比赛成功率、冷启动耗时和各成员机器的完整运行环境不能仅凭接口数认定。

本仓库发布白名单代码、公开目录与操作说明。账号/私钥、队长路径、VM、原始调用日志、个人训练答案和本机模型配置不随更新。依赖下载、题目部署、付费模型和比赛提交的授权分别处理，不在安装阶段自动派题。
