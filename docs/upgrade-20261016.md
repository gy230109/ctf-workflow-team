# 2026-10-16 增量升级

这次增加统一 CTF系统入口、团队身份/题型首读、共享方法与 Obsidian 笔记，以及新版运行扩展和自动 WP。保留每个人既有模型账号、Kali/SSH、任务和 WP；无须为了代码更新重建虚拟机。

## 从旧版迁移

在独立目录获取本次代码。旧版 team_upgrade.py 不支持 knowledge/、team/ 和新根文件；使用新目录里的脚本读取新清单，再指定原安装目录：

```powershell
.\upgrade-to-20261016.ps1 -Target '<原安装目录>' -Plan
.\upgrade-to-20261016.ps1 -Target '<原安装目录>'
```

Python 无法发现时用 -Python 指定原安装的解释器。目标省略时优先读取本机 .ctf-system 登记；没有登记则使用当前目录。先检查 Plan，再应用。新脚本使用新版路径清单验证器，并备份被更新的受管文件；不覆盖本机 config/*.json 或运行证据。

在原安装上直接 git pull 的用户，确认工作区没有需要保留的未提交更改；不 reset --hard、不 clean。已有本机配置仍保持忽略；AI 安装登记需要更新到当前路径。

## 身份和 Skill

升级后 connect_ai.py 同步当前 ctf-system Skill/MCP，保留其他工具配置。旧 Skill 作为兼容存在，日常使用 CTF系统。已有客户端在空闲时重连或开新会话，不能强杀其他 Agent。

将队内自己的角色卡放在原安装根目录 team-member.private.json，或执行：

```text
python tools/ctf_roles.py register --member B --profile saturday-four
python tools/ctf_roles.py show
```

角色卡可同时登记姓名；没有角色卡时可以用 --name 显式登记自己的姓名，信息只在本机。切换月底配置用 --profile full-seven。

## 检查范围

接口自检：python tools/ctf_os.py --selftest。基础桥与依赖：python tools/ctf_team.py verify。当前 AI 实际调用、主责依赖、WP、恢复和开机流程仍需本机验证。只复制 Skill、看到角色或注册工具数量不等于能解题。

本版 98 个通用工具，另有 9 个统一 MCP 方法。本机原有 104 工具中的三个 Jev 入口按既有要求留本机，三个绑定特定历史题的验证/探针入口不进入通用包；具体名称与数量见 manifest，不能用本机数量冒充。没有分发原始历史答案文件、题库管理员规则或私有原始记录；已有战例是经过处理的参考材料，不用于独立测试默认输入。
