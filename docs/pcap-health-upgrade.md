## 队友如何更新

已有安装按 [本日迁移说明](upgrade-20261016.md) 更新受管文件，保留模型账号、桥接配置、角色身份和 WP。直接 git pull 的安装先检查未提交修改，不 reset/clean。让自己的 AI 读取新版 AGENTS.md 并同步本仓库 ctf-system Skill；旧连接在空闲时重连，不打断其他题目。

NoobCTF 不把完整题解复制到本仓库。需要参考资料时运行：

```text
python tools/install_noobctf.py
```

安装器从固定官方源拉取固定提交、读取文本 Git 对象并建立本机索引，不运行下载的脚本；已有异源、异版本或本地改动的仓库会保留并报错。重复运行会复用符合条件的库与索引。该操作需要 Git 和网络。参考检索和读取都要求 `source=noobctf allow_reference=true`，不作为独立解题默认输入。

## 流量题用法

`ctf_tools` 查 `forensics_pcap`，通过同一题号的 `ctf_analyze` 或 `ctf_call` 调用：

| action | 用途 | 结果边界 |
|---|---|---|
| summary | 包与协议概览 | 只覆盖扫描上限内的数据 |
| streams | TCP/UDP 流定位 | 返回协议、流号、首包与端点 |
| follow | 读取明确 TCP stream_id | 文本摘要与真实导出文件 |
| http_objects | 导出 HTTP 对象 | 未执行的对象 ZIP、逐文件摘要 |
| dns | 查询/响应字段 | 包号和原始字段，不自动认定隐写 |
| usb | 原始 capdata 提取 | 不保证键盘明文或设备行为还原 |

使用 `local_file` 传本题原附件，保留同题号和输入 SHA256。通过既有 Kali 桥的固定身份传输，仅需要客机系统 Python 与 TShark，不依赖完整运行扩展或特定模型账号。没有相关依赖时按实际错误补齐，不复制他人机器配置。

HTTP 导出受时间、内存、文件数与总量检查约束；实际限制见工具实现。真实输出自动附入同题私有 WP，主数据下载或摘要失败返回失败。截图与数据附件分别标记，不能将表格或日志称作屏幕截图。

## 停滞复核和分题

统一调用自动附 `task_health`；`ctf_task_health` 查询同题累计工具耗时、新调用数、连续失败和相同参数/结果重复。提示不强制终止，不改变题目归属。80 次调用或 30 分钟工具时间是复核提醒，不是统一时间预算；模型用量与费用未知。状态轮询及连续调试/浏览器动作有正常重复豁免，明确复查也可带 `wp_repeat_expected=true`。

流量题仍按官方标签入队，公共题优先给空闲且工具实际可用的人。明确的新机会可以优先于无进展的旧路线，不能因为有新工具就打断有效推进。整题移交保留抓包、SHA256、流号、脚本、导出对象、失败和 WP，原负责人停止主动操作。跨机没有自动同步或自动合并任务的保证。
