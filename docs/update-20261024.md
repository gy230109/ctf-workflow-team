## 使用独立入口

已有系统并完成统一接口升级后，在自己的机器安装登记 `~/.ctf-system/location.json`；登记必须指向自己的系统根目录与 Python，不复制维护机路径。然后打开 `apps/ctf-desktop/CTF系统.exe`。也可以使用自己的 Python：

```text
python -X utf8 -B apps/ctf-desktop/app_server.py --root <自己的核心目录> --open
```

在 AI 接入页填写自己实际可用的模型地址、模型名和密钥。密钥仅保留在当前程序内存，不随仓库分发。
