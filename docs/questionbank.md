# 第一版题库与本机训练接入

本次第一版题库交接范围为 20 个题源、2,485 条初步去重记录（比赛题 1,108、课程练习 865、在线实验 512），原生成环境记录下载校验了 66 道题/86 个附件，并包含六人六天 36 题轮换计划。

这些数字来自题库生成交付记录。它们不能代替本机附件、目录与运行环境的验收。实际公共目录/脚本交接完成后，以 ctf-questionbank 的 stats 和下载记录为准；个别题需要原平台登录或专用运行环境。

在自己的仓库使用题库工具筛选一题，下载/核对附件到本机独立目录，再用 CTF-OS local_file 上传并交 Kali 执行。题面、参考答案、个人 WP 保持隔离；详情见 Skill references/questionbank.md。资料没有落到本机时不执行云端 sandbox 路径，也不把它写成可用本机路径。

本批原文件和下载清单仍在交接，发布验收会更新这里的实际接入状态。原始附件优先按来源 URL/SHA 在各自机器下载；仓库不分发平台登录态、私密答案或个人训练记录。
