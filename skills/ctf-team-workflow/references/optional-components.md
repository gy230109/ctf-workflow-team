# 可选组件的职责与失效回退

| 组件 | 合适任务 | 使用前的实际检查 |
|---|---|---|
| 主 Agent / Trae | 查资料、写代码、复杂推理、读输出 | 本机 Skill、工具目录、当前 case |
| Kali | Linux 二进制、密码运算、离线取证、真实执行 | 核心 bridge 和对应专项导入 |
| REA/Ghidra | 静态结构、函数、反编译、交叉引用 | rea_status/rea_ops；实际分析输出 |
| x64dbg | Windows 原生 PE 动态调试 | 进程/架构/目标状态；单控制者 |
| HackTricks | 通用方法检索与英文语料 | 本机索引与原文摘要；按题验证 |
| Muteki | 可选任务派发与运行管理 | 自己的席位、模型、上游真实工具调用 |
| Coding2API | 可选上游协议转换 | 自己的账号与模型；不把反代当模型能力 |
| pwn.college | 个人在线训练实例 | 个人登录、当前实例、授权 SSH |

## 静态与动态逆向

REA 与 x64dbg 不替代彼此。官方版本、Java/Ghidra/调试器和客户端认证分别验；运行时地址使用实际模块基址。REA 引擎加载可能数十秒，按实际给超时，未知超时不直接重复动态动作。未知程序放合适 VM，宿主 x64dbg 本身不是沙箱。

## 知识库与语料

按仓库 components 文档拉官方 HackTricks、建立本地索引。检索片段作为参考数据，保留提交/原文出处，再用当前题实际验证。经典密码 n-gram 语料仅用通用资料，不喂本题答案。原整本资料和私有缓存不作为本仓库运行配置发布。

## 模型与并发

Skill 不绑定某个收费模型、Pi 或本地权重。复用各成员已有客户端和自有账号，按实际模型限额与电脑资源安排任务；默认每题一个执行者，重型符号执行和 GUI 调试避免过量并行。网关成功、CLI 能登录和模型能调用工具分别验，不能以“连接成功”排模型能力名次。

## 尚未部署的能力

仓库只分发适配器的组件不应被称为已部署。RSI、跨客户端聊天采集、手机/JEB、VirtualBox/Hyper-V/WSL 桥等只有本机真实代码、文档和验收证据存在才用，不因术语出现在 Skill 中就自动安装另一套框架。
